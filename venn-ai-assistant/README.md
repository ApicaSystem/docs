# VENN AI ASSISTANT

Venn is the AI assistant built into every screen of Apica Ascent. You ask in plain language; Venn answers from your live data and drafts the things you would otherwise build by hand. Nothing Venn drafts is saved until you review it and press Save yourself.

### What you can do with Venn

| You want to...                      | Ask Venn                                                     | Learn more                                                    |
| ----------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------- |
| Find and understand logs            | _"Show me errors from the payments app in the last 2 hours"_ | [Ask Venn about your data](ask-venn-about-your-data.md)       |
| Cut log volume or mask PII          | _"Reduce log volume from the checkout service"_              | [Pipelines with Venn](pipelines-with-venn.md)                 |
| Build or edit a dashboard           | _"Create a dashboard to monitor a service"_                  | [Dashboards and queries](dashboards-and-queries-with-venn.md) |
| Create alerts and SLOs              | _"Alert me when error rate passes 5 per minute"_             | [Alerts and SLOs](alerts-and-slos-with-venn.md)               |
| Set up sources, forwarders, agents  | _"Create a Datadog forwarder for the prod namespace"_        | [Create resources with Venn](create-resources-with-venn.md)   |
| Use Ascent from your own AI clients | Connect Claude Code, Claude Desktop, Cursor and others       | [Connect an MCP client](connect-your-own-ai-client-mcp.md)    |
| Answer "how do I" questions         | _"How do I set up a Kafka source?"_                          | Venn answers from the Apica docs, inline in chat              |
